# Расширение Chrome «Детектор ИИ-текста»

## Установка (режим разработчика)
1. Открой `chrome://extensions`, включи «Режим разработчика» (переключатель справа вверху).
2. Нажми «Загрузить распакованное расширение» и выбери эту папку (`extension`).
3. Открой любую страницу с текстом (уже открытые вкладки нужно перезагрузить), нажми на значок расширения → «Проанализировать страницу».

Абзацы подсвечиваются жёлтым («возможно ИИ») или красным («вероятно ИИ»); при наведении — вероятность и признаки, повлиявшие на оценку.

## Модели и библиотеки
Гибридный детектор использует языковые модели в формате ONNX (GPT-2 small для английского, ruGPT-3 small для русского) и библиотеки Transformers.js и ONNX Runtime Web.
1. Скачай с Google Диска (папка `ai-text-detector`) `extension_assets_v2.zip` и распакуй **внутрь папки `extension`** — появятся `models/`, `vendor/` и `model/weights.json`.
2. Затем туда же распакуй `extension_assets_v3.zip` **с заменой файлов** — обновятся русская модель и `model/weights.json`.
3. В `chrome://extensions` нажми «Обновить» у расширения.

Папки `models/` и `vendor/` (~360 МБ) в репозиторий не попадают (см. .gitignore).

## Как работает анализ
- Сначала абзац получает **предварительную оценку** только по стилю текста (мгновенно, пунктирная рамка), затем её уточняет гибридный детектор с языковой моделью.
- В настройках можно выбрать вычисления на процессоре (WebAssembly, число потоков) или на видеокарте (WebGPU).
- «Настройки → Замер скорости…» открывает страницу замера: время загрузки моделей, прогрева и анализа текстов разной длины, потребляемая память.

## Структура
- `manifest.json` — описание расширения (Manifest V3)
- `content/content.js` — извлечение абзацев, ленивый анализ (Intersection Observer), подсветка
- `background/service-worker.js` — передача сообщений, создание offscreen-документа
- `offscreen/` — скрытый документ и Web Worker, в котором считается модель
- `lib/features.js` — стилометрические признаки (копия `research/stylometry.py`), `lib/classifier.js` — логистическая регрессия
- `popup/` — окно настроек
- `bench/` — страница замера производительности

Если в `weights.json` нет признаков языковой модели (стилометрическая версия из шага 1), модели и библиотеки не нужны.
